# Implementation and Documentation

**Target date:** 26 September 2026

## Implementation summary

The implemented MVP must demonstrate this path:

1. Owner registers/logs in and manages restaurant menu data.
2. Owner creates a table and generates an opaque QR token.
3. Customer scans QR, sees the correct nutrition menu, manages cart, and places an order.
4. Staff sees the order and changes status.
5. Owner views a basic report.

## Final documentation contents

- Title page, certificate, declaration, acknowledgement, abstract, and index according to college format.
- Introduction, existing/proposed system, objectives, feasibility, requirements, methodology.
- Architecture, database design, ERD, use cases, activity diagrams, process/class design, and DFD.
- Module descriptions, input/output screens, security controls, testing evidence, limitations, conclusion, future scope, and references.
