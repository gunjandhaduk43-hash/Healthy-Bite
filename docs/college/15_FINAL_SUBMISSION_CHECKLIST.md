# Final Project Report Submission Checklist

**Final date:** 30 September 2026

## Report checklist

- [ ] Title page with exact project title, student details, college, academic year, and guide.
- [ ] Certificate/declaration/acknowledgement as required by college.
- [ ] Abstract, index, list of figures, and list of tables.
- [ ] Proposal, investigation, requirements, feasibility, and scope.
- [ ] ERD, data dictionary, use case/activity, process/class, and DFD diagrams.
- [ ] Architecture, module descriptions, database details, and security design.
- [ ] Implementation screenshots with captions.
- [ ] Test plan, test cases, test results, limitations, conclusion, future scope, and references.
- [ ] Grammar, page numbers, figure numbers, and final formatting checked.

## Software checklist

- [ ] Complete source code and database SQL export included.
- [ ] Installation instructions for XAMPP and database import included.
- [ ] Demo user credentials provided separately for evaluation.
- [ ] No `.env`, real passwords, private data, or unnecessary upload files included.
- [ ] QR ordering demo tested from a mobile browser.
- [ ] Final backup stored safely in two locations.

## Viva preparation

- [ ] Explain why PHP/MySQL and Bootstrap were selected.
- [ ] Demonstrate owner setup -> QR scan -> order -> staff status update.
- [ ] Explain tables, primary/foreign keys, normalization, and transactions.
- [ ] Explain prepared statements, password hashing, CSRF, sessions, RBAC, and secure QR tokens.
- [ ] Clearly state future features not included in the current version.
