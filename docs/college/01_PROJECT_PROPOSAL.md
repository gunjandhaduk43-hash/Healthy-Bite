## Abstract

Healthy Bite is a web-based system that enables restaurants to provide a QR-code digital menu and accept table orders. Customers scan a table QR code, view food details including nutrition, ingredients, allergens, price, and diet type, add items to a cart, and place an order. Restaurant owners manage menus, tables, QR codes, and staff; staff update order status. The system uses PHP, MySQL, HTML, CSS, Bootstrap 5, and JavaScript.

## Objectives

- Digitize restaurant menus and table ordering.
- Provide nutrition and allergen transparency.
- Reduce manual order-taking effort.
- Protect table ordering through secure random QR tokens.
- Demonstrate PHP sessions, CRUD, MySQL, authentication, and responsive web design.

## Deliverables

Working web application, database schema, diagrams, test evidence, user guide, screenshots, and final project report.

## Limitations

The college release does not include real online payment, delivery, inventory, loyalty, AI, or mobile apps.
