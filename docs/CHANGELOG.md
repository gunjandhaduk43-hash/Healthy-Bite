# Changelog

## [Unreleased]

### Added

- Premium SaaS UI/UX design foundation featuring the Emerald green primary theme, Outfit (display) & Inter (body) typography, and Bootstrap Icons.
- Modern responsive dashboard sidebar navigation layout for desktop view alongside collapsible action-rich menu for mobile.
- Completely redesigned Owner Sign In, registration inputs (with group icons), and error layout sheets.
- Polished metric cards with graphics, status badges (pulse animation), and structured multi-column restaurant profile form editor.
- Complete enterprise-grade Entity Relationship Diagram (ERD) covering all 14 SaaS modules (Authentication, Restaurants, Branches, Menu, Nutrition, Tables, Customers, Orders, Kitchen, Inventory, Payments, Marketing, Reviews, Reports) with data models, normalization checks, and scalability rules.
- Added a simplified alternative MVP ERD edition mapping the 10 core tables (User, Restaurant, Category, FoodItem, Table, QrToken, QrSession, Order, OrderItem, Payment) suited for report documentation drawing limits.


- Stage 1 custom PHP MVC scaffold with routing, views, PDO database connection, CSRF handling, flash messages, and route middleware.
- Restaurant owner registration/login/logout, session regeneration, protected dashboard, and tenant-scoped restaurant profile update.
- XAMPP setup guide and Stage 1 MySQL schema for users and restaurants.
- Current page inventory with implemented routes, access rules, page behaviors, and later-stage page plan.
- Reproducible demo restaurant-admin account seed and credential documentation.
