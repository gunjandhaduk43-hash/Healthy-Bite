## Future modules

Inventory, payment gateway integration, loyalty, coupons, customer accounts, reservations, delivery, notifications, multi-branch support, advanced analytics, and AI recommendations are deliberately excluded from the assessed MVP.

## Module completion definition

Each completed module includes routes, controller, service, repository, validation, responsive views, permission checks, database changes, manual test evidence, and an update to the relevant documentation.
